# Custom 3D Car Models (.glb)

You can place your own 3D car models in this folder! The game supports Draco-compressed `.glb` and `.gltf` models.

## Expected File Names:
1. `car_apex.glb` - For Apex GT
2. `car_muscle.glb` - For Viper Muscle
3. `car_hyper.glb` - For Phantom Hyper

## Recommended Free 3D Model Sources (CC0 / Free License):
- **Kenney.nl**: [Kenney Car Kit](https://kenney.nl/assets/car-kit) (Free, low-poly, optimized for WebGL)
- **Poly Pizza**: [poly.pizza](https://poly.pizza) (Search "sportscar", "racing car", download .glb)
- **Sketchfab**: [sketchfab.com](https://sketchfab.com) (Filter by downloadable & CC Attribution)

## Auto-Fallback:
If no `.glb` file is detected or if downloading fails, Apex Drift 3D automatically renders its built-in procedural high-detail 3D sports car models, ensuring the game always runs smoothly without errors!
